SpectraUtils

Utilities for building physical spectroscopic models (species states, transitions, population distributions, and full emission/radiance spectra) on top of the line-shape/line-synthesis primitives provided by the sibling package SpectralLines.jl.

SpectraUtils.Boltzmann — Type
Boltzmann(partition_function, E0, parent[, temperature_function])
Boltzmann(; partition_function, E0, parent, temperature_function = p -> p[Val(:T)])

Thermal population of the states under parent (see State):

\[f(s) = \frac{g_s}{Q(T)} \exp\left(-\frac{hc\,(E_s - E_0)}{k_B T}\right)\]

and zero for states outside parent. partition_function is Q, callable as Q(T) and computed from the same energy zero E0 [cm⁻¹]. T comes from temperature_function(params), by default params.T; capture a different key statically (p -> p.T_rot).

An unwrapped Boltzmann is global LTE (is_LTE), which gives RadianceSpectrum its Planck fast path. With using ExoMol, Boltzmann(data, parent) builds one from an ExoMol dataset; for HITRAN use HITRAN.partition_function as Q with E0 = 0.

SpectraUtils.ChebyshevBackground — Type
ChebyshevBackground(lo, hi, degree; key = :background)

A Chebyshev-polynomial background, callable as (xs, params) -> values, the form every model's background field expects:

sp = EmissionSpectrum(; transitions, distribution_function, lineshape_function,
                        background = ChebyshevBackground(300.0, 320.0, 3))

The coefficients live in params under key, so they are fit parameters like any other:

params = ComponentVector(T = 1000.0, background = [0.4, 0.05, -0.01, 0.002])
priors = ComponentVector(T = Normal(900.0, 200.0),
                         background = [Normal(0.0, 1.0) for _ in 1:4])

degree + 1 coefficients are expected; n_coefficients returns that. Degree 0 is a constant offset, degree 1 a straight line.

Give the actual fitted range as lo/hi: points outside still evaluate, but the conditioning holds only inside.

SpectraUtils.DistributionFunction — Type
DistributionFunction

Abstract supertype for state populations: callable as f(state, params), returning the population of state (a fraction, or a number density if the distribution is scaled to one) at the parameters params. The spectrum models call it on the upper and lower state of every transition.

Any (state, params) -> population function works in place of a subtype; DistributionFunction(f) passes functions and subtypes through and wraps a number in a ConstantDistribution.

SpectraUtils.ElectricDipoleTransition — Type
ElectricDipoleTransition(lower, upper, wavenumber, A, pressure_shift = 0.0)

A radiative transition between a lower and upper State, at wavenumber [cm⁻¹] with Einstein A coefficient A [s⁻¹]. Construct with ElectricDipoleTransition(lower, upper, A), taking wavenumber from the states' energy difference, or pass wavenumber directly.

The input to the spectrum models; make_transition_list builds a Vector of these from a line-list source (ExoMol, or HITRAN via SpectraUtils.HITRAN).

pressure_shift is the shift of the line centre per unit pressure in cm⁻¹/atm (HITRAN's δ_air). The models apply it only through a lineshift_function of the SpeciesModel, e.g. (t, p) -> t.pressure_shift * p.P.

SpectraUtils.LineCache — Type
LineCache()

Cache of per-transition line vectors, so a spectrum model can rebuild its lines on every call (fitting, AD) without reallocating.

One LineCache covers any number of slots, requested by name in fill_lines!. EmissionSpectrum/RadianceSpectrum use it internally; it is exported for custom models, see examples/custom_spectrum_model.jl.

A LineCache is not thread-safe, so use one model instance per thread. One buffer is kept per numeric type seen and never freed.

SpectraUtils.SpectralRadiance — Type
SpectralRadiance()

amplitude convention for EmissionSpectrum: photon-energy weighted (h·c·ν̃/4π) · A_ul · f_u, i.e. RadianceSpectrum's emission coefficient j. With number_density_function/path_length_function set, the spectrum is the optically-thin limit of RadianceSpectrum, in W·cm⁻²·sr⁻¹·(cm⁻¹)⁻¹.

SpectraUtils.State — Type
State{E,V,J,EN,D}

A quantum state: electronic_state, vibrational_state, rotational_state (any label type, e.g. Symbol/Int, or nothing if unspecified), plus optional energy [cm⁻¹] and degeneracy. Construct with State(electronic, vibrational=nothing, rotational=nothing), which leaves energy and degeneracy nothing, or with all five: State(electronic, vibrational, rotational, energy, degeneracy).

child in parent holds when the electronic states are equal and parent's vibrational and rotational states are each nothing (a wildcard) or equal to child's. Boltzmann tests membership in its parent this way; StateResolved groups states by e.g. vibrational_state.

SpectraUtils.StateResolved — Type
StateResolved(state_type, distribution)
StateResolved(; state_type, distribution)

A separate distribution per group of states: state_type(s) gives the group key of state s (e.g. vibrational_state), and distribution maps keys to distributions, evaluated as distribution[key](s, params). States whose key is missing have zero population. Wrap a fixed value in a ConstantDistribution. For a non-equilibrium population, such as one rotational Boltzmann per vibrational level:

StateResolved(vibrational_state, Dict(0 => bd_v0, 1 => bd_v1))

SpectraUtils.absorption_cross_section — Method
absorption_cross_section(tr::ElectricDipoleTransition) -> Float64

Integrated absorption cross section in cm (equivalently cm²·cm⁻¹): the prefactor that, times a lineshape of unit area over wavenumber (∫φ(ν̃)dν̃ = 1, so φ is itself in cm) and a number density [cm⁻³], gives an absorption coefficient in cm⁻¹.

From the Einstein A coefficient via the B-coefficient relations:

\[\int_{-\infty}^{\infty} \sigma(\tilde{\nu})\,d\tilde{\nu} = \frac{g_u}{g_l}\frac{A_{ul}}{8\pi\,c\,\tilde{\nu}_0^2}\]

with $g_u$, $g_l$ the upper/lower degeneracies, $A_{ul}$ the Einstein A coefficient [s⁻¹], $c$ the speed of light in cm s⁻¹, and $\tilde{\nu}_0$ the transition wavenumber [cm⁻¹].

source
SpectraUtils.absorption_line — Method
absorption_line(t, distribution_function, lineshape_function, params)

Uninstrumented absorption line of transition t: amplitude σ₀ · (f_l − f_u·g_l/g_u), the integrated cross section (absorption_cross_section) weighted by the population difference, net of stimulated emission.

f_l and f_u are not clamped at zero: only their difference is identifiable, and a negative value expresses gain (inverted lines).

SpectraUtils.calculate_radiance_lines! — Method
calculate_radiance_lines!(αret, jret, xs, dual_lines, method::Union{PointSample,BinAverage})

In-place calculate_radiance_lines: fills αret/jret with the absorption/emission coefficient sums over dual_lines.

Only PointSample and BinAverage are supported; there is no LDM equivalent for dual-amplitude (α, j) lines. Their min_amplitude must be unset: it has no single meaning for lines with two amplitudes. αret and jret must share indices with xs, and wing_cut needs an ascending grid.

SpectraUtils.convolve_spectrum — Method
convolve_spectrum(model, xs, params, instrument_function) -> Vector

FFT-convolve any model(xs, params) -> Vector with instrument_function. model is evaluated on a grid padded by convolution_support(instrument_function) on each side, so the crop back to xs avoids edge effects (exactly ±fwhm for Triangular, zero beyond that).

Needed for instrument shapes with no closed-form combination with the line shape, e.g. Triangular; Gaussian/Lorentzian/Voigt combine analytically and are applied per line inside the models. Pass instrument_function = (wn, p) -> nothing to model so its per-line convolution is a no-op, and make xs fine enough to resolve the natural linewidth.

xs must be ascending and uniformly spaced; anything else throws an ArgumentError. Spacings within 1% of the first one count as uniform.

SpectraUtils.gamma_hard_sphere — Method
gamma_hard_sphere(p, T; μ, cs) -> γ [cm⁻¹]

Lorentzian HWHM of pressure broadening at pressure p [Pa], temperature T [K], reduced mass μ [kg], and collision cross-section cs [m²], using the hard-sphere model: the collision rate n·cs·v̄ over 2πc,

\[\gamma = \frac{n\,\sigma\,\bar{v}}{2\pi c},\qquad n = \frac{p}{k_B T},\quad \bar{v} = \sqrt{\frac{8 k_B T}{\pi \mu}}\]

N₂ self-broadening at 1 atm and 300 K (cs ≈ 4.5e-19 m²) gives γ ≈ 0.04 cm⁻¹.

source
SpectraUtils.gamma_lifetime — Method
gamma_lifetime(tau) -> γ [cm⁻¹]

Lorentzian HWHM due to a finite state lifetime tau [s]:

\[\gamma = \frac{1}{4\pi c\,\tau}\]

where $c$ is the speed of light in cm s⁻¹. For a purely radiative state, $\tau = 1 / \sum_l A_{ul}$; for predissociating states it should include the non-radiative decay rate as well.

Add to the pressure-broadening $\gamma$ before constructing a Voigt profile:

γ_total = gamma_hard_sphere(p, T; μ, cs) + gamma_lifetime(tau)
Voigt(sigma_doppler(f0, T; m), γ_total)

SpectraUtils.gamma_pressure — Method
gamma_pressure(p_atm, T, x_self; gamma_air, n_air,
                        gamma_self=gamma_air, n_self=n_air, Tref=296.0) -> γ [cm⁻¹]

Air plus self broadening in one call: the two-term sum above, with partial pressures derived from the mole fraction x_self.

gamma_self/n_self default to the air values, matching ExoMol datasets that declare one dataset-wide coefficient rather than separate air and self ones (SiO EBJT).

γ = gamma_pressure(P / 101325, T, x; gamma_air = 0.07, n_air = 0.5)

SpectraUtils.gamma_pressure — Method
gamma_pressure(p_atm, T; gamma_ref, n, Tref=296.0) -> γ [cm⁻¹]

Lorentzian HWHM of pressure broadening from a tabulated HITRAN/ExoMol coefficient gamma_ref [cm⁻¹/atm] at reference temperature Tref [K] (296 K by convention), scaled to pressure p_atm [atm] and temperature T [K]:

\[\gamma = \gamma_{ref}\,p_{atm}\,(T_{ref}/T)^n\]

The tabulated-coefficient approach of HITRAN/ExoMol line lists, as opposed to gamma_hard_sphere's kinetic-theory model. gamma_ref/n come from a per-line .broad file, or from a dataset-wide default in the .def.json for datasets without one (SiO EBJT: gamma_ref=0.07, n=0.5).

For a mixture, sum one term per diluent weighted by partial pressure:

γ = gamma_pressure(p_atm * (1 - x_self), T; gamma_ref=γ_air, n=n_air) +
    gamma_pressure(p_atm * x_self, T; gamma_ref=γ_self, n=n_self)

SpectraUtils.is_LTE — Method
is_LTE(::DistributionFunction) -> Bool

Whether a distribution function is a single global thermal population at one temperature: true only for a bare, unwrapped Boltzmann. RadianceSpectrum uses it to dispatch to the closed-form Planck source function.

A Boltzmann inside a ProductDistribution/StateResolved (e.g. one rotational Boltzmann per vibrational level) is not global LTE and gives false.

SpectraUtils.make_transition_list — Method
make_transition_list(lines::Vector{HITRAN.Line}) -> Vector{ElectricDipoleTransition}

Convert parsed HITRAN/HITEMP lines into ElectricDipoleTransitions. Uses only the direct HITRAN160 fields wav, A, El, gp, gpp, so LTE modelling works without decoding the globu/globl/locu/locl quantum-number strings.

Electronic/vibrational/rotational fields are left as :X/nothing placeholders; decoding those strings is a prerequisite for driving non-LTE distributions such as StateResolved from HITRAN.

The Einstein A is abundance-free, unlike HITRAN's intensity S, so number_density_function must return the number density of the isotopologue itself. For natural abundance, scale by HITRAN.molparam(mol_id, iso).abundance. Lines of several isotopologues give a warning: filter to one per SpeciesModel.

Lines without an Einstein A, statistical weights or a lower-state energy (unassigned lines) throw an ArgumentError, since they would turn the spectrum into NaN. Drop them first with filter(HITRAN.is_usable, lines); they are not dropped here, so that lines[i] keeps matching the i-th transition.

The air pressure shift δ_air becomes the transition's pressure_shift (0 where the line list leaves it blank). Apply it with a lineshift_function on the SpeciesModel, e.g. (t, p) -> t.pressure_shift * p.P for P in atm.

SpectraUtils.radiance_line — Method
radiance_line(t, distribution_function, lineshape_function, params)

Line of transition t carrying two amplitudes on one shape: the absorption amplitude of absorption_line plus the emission amplitude (h·c·ν̃/4π)·A·f_u. The photon-energy and per-steradian factors are always applied here: j must match planck_radiance's units for j/α to be a valid source function.

SpectraUtils.sigma_doppler — Method
sigma_doppler(f0, T; m) -> σ [cm⁻¹]

SpectraUtils.update_or_fill_lines! — Method
update_or_fill_lines!(cache, name, amps_name, transitions, build_line,
                      build_amplitude, instrument_function, params) -> Vector

fill_lines! for params-independent shapes (see StaticLineshapes): when the slot already holds a line vector of the right concrete type and length, only the amplitudes are recomputed (build_amplitude(t, params)) and written with SpectralLines.update_lines!, keeping the shapes and instrument convolutions of the first build. Any type change (a ForwardDiff pass, a different chunk size) keys a fresh buffer and rebuilds, as in fill_lines!.

Staleness is checked on the length and on the first line, whose position and convolved shape must equal the freshly built ones; otherwise everything is rebuilt. Do not mutate transitions in place beyond that. amps_name is a second slot holding the amplitude scratch vector.

SpectraUtils.upper_manifold — Method
upper_manifold(transitions) -> State

The electronic manifold shared by the upper states of transitions, as a State for use as a Boltzmann parent. Throws if they span more than one manifold.

Boltzmann(data, parent) picks its partition function by whether parent restricts the state set, so a parent that misdescribes the list gives the wrong Q(T).

tl = filter(t -> electronic_state(t.upper) == :A, make_transition_list(data))
parent = upper_manifold(tl)
bd = Boltzmann(data, parent)
