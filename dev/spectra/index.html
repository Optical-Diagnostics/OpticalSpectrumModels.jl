Spectra

Five models build a spectrum from a list of quantum transitions, a population distribution, and a line-shape function:

  • EmissionSpectrum: optically-thin emission, summing A_ul · f_u · φ(ν) per line (photon-rate by default, energy-weighted via amplitude = SpectralRadiance()).
  • RadianceSpectrum: self-absorbing radiative transfer through one or more uniform slabs, with an LTE fast path (Kirchhoff's law) and a general non-LTE α/j path.
  • AbsorptionCoefficientSpectrum: the absorption coefficient α(ν) itself.
  • AbsorbanceSpectrum: Napierian absorbance α·L = −ln(I/I₀).
  • TransmittanceSpectrum: normalized transmission e^{−αL}.

Every model takes a Tuple of SpeciesModel via its species keyword: several species, each with its own line list, distribution, number density and synthesis method, share one slab, with coefficients added before anything nonlinear. The flat per-species keywords are shorthand for a single species. All models but AbsorptionCoefficientSpectrum also take a slabs keyword, a Tuple of Slab, for a line of sight through several regions.

Example

using SpectraUtils, ComponentArrays

# A toy band: rotational levels J of an excited state, all radiating to one
# ground state. Energies in cm⁻¹.
ground = State(:X, 0, 0, 0.0, 1)
upper(J) = State(:A, 0, J, 20000.0 + 2.0 * J * (J + 1), 2J + 1)
transitions = [ElectricDipoleTransition(ground, upper(J), 1.0e6) for J in 0:20]

# Thermal population of the A state, measured from its lowest level.
c2 = 1.4387769                                   # hc/k, cm·K
Q(T) = sum((2J + 1) * exp(-c2 * 2.0 * J * (J + 1) / T) for J in 0:20)
bd = Boltzmann(Q, 20000.0, State(:A))

wavenumbers = range(19990.0, 20900.0, length = 9101)
sp = EmissionSpectrum(;
    species = SpeciesModel(;
        transitions,
        distribution_function = bd,
        lineshape_function = (t, p) -> Voigt(sigma_doppler(t.wavenumber, p.T; m = p.mass), p.gamma),
        method = BinAverage(bin_width = step(wavenumbers), wing_cut = 50.0)),
    instrument_function = (wn, p) -> Gaussian(p.sigma_inst),
)

params = ComponentVector(T = 1500.0, mass = 4.65e-26, gamma = 0.05, sigma_inst = 0.2)
spectrum = sp(wavenumbers, params)

Read parameters as p.T or p[Val(:T)]. Indexing a ComponentVector with a runtime Symbol (p[:T]) dispatches dynamically and allocates on every line.

API

SpectraUtils.SpeciesModel — Type
SpeciesModel(; transitions, distribution_function, lineshape_function,
               number_density_function=(p) -> 1.0, lineshift_function=nothing,
               method=PointSample())

One radiating/absorbing species: its line list, population distribution, lineshape, number density [cm⁻³], and line-synthesis method. Every spectrum model takes a Tuple of these via its species keyword; the coefficients add before anything nonlinear, so several species share one slab:

sp = RadianceSpectrum(;
    species = (
        SpeciesModel(; transitions = tl_OH, distribution_function = bd_OH,
                       lineshape_function = lsf_OH,
                       number_density_function = p -> p.N_OH),
        SpeciesModel(; transitions = tl_H2O, distribution_function = bd_H2O,
                       lineshape_function = lsf_H2O,
                       number_density_function = p -> p.N_H2O,
                       method = LDM()),
    ),
    path_length_function = p -> p.L,
)

method is per-species, so a sparse atomic system (PointSample) and a dense molecular band (LDM/SparseLDM) can share a slab. For LDM/SparseLDM a synthesis workspace is created automatically and reused across calls. A model's flat per-species keywords are shorthand for one SpeciesModel with the default PointSample().

lineshift_function: (t, params) -> Δν̃ [cm⁻¹], added to every line centre; nothing (default) leaves the centres at t.wavenumber. The pressure shift of a HITRAN line list is (t, p) -> t.pressure_shift * p.P with p.P in atm. A shift that depends on params disables the StaticLineshapes fast path, since line positions then change between calls.

Slab and instrument properties (path_length_function, incident_radiance, background, wavenumber_function, instrument_function, amplitude) stay on the model.

source
SpectraUtils.Slab — Type
Slab(; species, path_length_function)

One uniform slab of a line of sight: a Tuple of SpeciesModel (or a single one) plus its geometric length (params) -> L [cm]. The geometric models take a Tuple of these via their slabs keyword; slabs[1] is the slab farthest from the observer, and light exits slabs[end]:

sp = RadianceSpectrum(; slabs = (
    Slab(; species = core_species, path_length_function = p -> p.L_core),  # back
    Slab(; species = edge_species, path_length_function = p -> p.L_edge),  # front
))

Per-slab conditions come from the parameter keys the species' functions capture (p.T_core vs p.T_edge via Boltzmann's temperature_function, p.N_core vs p.N_edge, …). The species + path_length_function model keywords are shorthand for a one-slab tuple.

source
SpectraUtils.StaticLineshapes — Type
StaticLineshapes(f)

Marks a params-independent lineshape function: f(t) -> LineShape takes only the transition, instead of the default (t, params) -> LineShape.

SpeciesModel(; transitions, distribution_function,
               lineshape_function = StaticLineshapes(t -> Voigt(σ_D(t), γ)), ...)

The models then build the shapes and their instrument convolutions once and update only the amplitudes on later calls, which speeds up fitting loops, also under ForwardDiff.

transitions must not be mutated in place. An instrument_function that depends on params is allowed but loses the speed-up: whenever the first line's convolved shape changes, all shapes are rebuilt.

SpectraUtils.EmissionSpectrum — Type
EmissionSpectrum(; species, path_length_function=(p) -> 1.0,
                   instrument_function=(wn, p) -> nothing,
                   wavenumber_function=(x, p) -> x,
                   amplitude=PhotonRate(),
                   background=nothing)
EmissionSpectrum(; slabs, ...)

Optically-thin emission model: Σₖ Lₖ · Σₛ Nₛ · Σ A_ul · f_u(state) · φ(ν) over the transitions of every SpeciesModel, with no self-absorption (so slabs add). Call as sp(xs, params) (allocating) or sp(ret, xs, params) (in-place), with params a ComponentVector. RadianceSpectrum is the self-absorbing counterpart.

Instead of species, the flat keywords transitions, distribution_function, lineshape_function, number_density_function build a one-species tuple with the default PointSample() method; for another method, pass a SpeciesModel.

Keyword arguments

  • species: Tuple of SpeciesModel (or one SpeciesModel)
  • path_length_function: (params) -> L [cm], default 1.0. Shared by all species; each species carries its own number density.
  • slabs: Tuple of Slab for a multi-slab line of sight, mutually exclusive with species/path_length_function (one-slab sugar).
  • instrument_function: (wavenumber, params) -> LineShape | nothing; nothing (default) applies no instrumental broadening. Instrument profiles with no closed-form combination with the lineshape (e.g. Triangular) go through convolve_spectrum instead.
  • wavenumber_function: (xs, params) -> wavenumbers, for wavelength calibration or axis remapping. Default identity.
  • amplitude: PhotonRate() (default) or SpectralRadiance(). Across a wide band the two differ in relative line intensities (a factor ν̃), not just units.
  • background: constant or (xs, params) -> offset, added to the spectrum

Example

# CO (HITRAN molecule 5, isotopologue 1) from a local .par file
lines = HITRAN.read_par("05_HITEMP2019.par"; wn_min = 2100, wn_max = 2200)
tl = make_transition_list(filter(l -> l.iso == 1, lines))
m = molecular_mass_kg(HITRAN.molparam(5, 1))
sp = EmissionSpectrum(;
    transitions = tl,
    distribution_function = Boltzmann(HITRAN.partition_function(5, 1), 0.0, State(:X)),
    lineshape_function = (t, p) -> Voigt(sigma_doppler(t.wavenumber, p.T; m), p.gamma),
    instrument_function = (wn, p) -> Gaussian(p.sigma_inst),
)
spectrum = sp(2100:0.01:2200, ComponentVector(T = 1500.0, gamma = 0.05, sigma_inst = 0.1))

SpectraUtils.RadianceSpectrum — Type
RadianceSpectrum(; species, path_length_function,
                    instrument_function=(wn, p) -> nothing,
                    wavenumber_function=(x, p) -> x,
                    incident_radiance=nothing, background=nothing)
RadianceSpectrum(; slabs, ...)

Self-absorbing radiative transfer through uniform, non-scattering slabs. Per slab, computes α(ν) = Σₛ αₛ(ν) and j(ν) = Σₛ jₛ(ν) over its SpeciesModels and folds I(ν) ← S(ν)·(1 − e^{−α(ν)L}) + I(ν)·e^{−α(ν)L} with source function S(ν) = j(ν)/α(ν), starting from incident_radiance behind slabs[1] and exiting slabs[end] toward the observer. Coefficients add before the RTE, so overlapping lines of several species self-absorb against each other. EmissionSpectrum is the optically-thin counterpart.

Keyword arguments

species (or the flat single-species keywords, see SpeciesModel) and wavenumber_function as for EmissionSpectrum, plus:

  • slabs: Tuple of Slab, ordered far side first; mutually exclusive with species/path_length_function (one-slab sugar).
  • path_length_function: (params) -> L [cm]; required in the one-slab form. Each species carries its own number_density_function, e.g. (p) -> p.P * p.x / (kB * p.T) / 1e6 for pressure p.P [Pa], mole fraction p.x, temperature p.T [K].
  • instrument_function: must return nothing (the default); a returned shape throws. Use convolve_spectrum, which convolves after the radiative transfer.
  • incident_radiance: I₀(ν) entering behind slabs[1], attenuated by e^{−αL}; constant, callable (ν, params) -> ... on the mapped wavenumber axis, or nothing (default, I₀ = 0)
  • background: instrumental offset (dark signal, straylight) added to the final spectrum on the raw xs axis. Not attenuated by the slab.

Per-species method is unrestricted only on the LTE fast path below; the non-LTE path supports PointSample/BinAverage (see calculate_radiance_lines!).

With BinAverage, α and j are bin-averaged before the radiative transfer. That is not the bin-averaged radiance; the error is second order in the bin width.

LTE fast path

Decided per slab: when every species' distribution satisfies is_LTE (an unwrapped Boltzmann) and their temperatures are equal at the current params, the source function is planck_radiance in closed form and j is never computed. Otherwise the slab takes the general (α, j) path. The two paths differ at the 1e-4 level across a line: Planck is evaluated at each grid point here, and at the line centre in the general path.

A bare Boltzmann whose parent excludes lower states of its species' transitions throws at construction: those populations are zero, which makes the absorption coefficient negative.

SpectraUtils.AbsorptionCoefficientSpectrum — Type
AbsorptionCoefficientSpectrum(; species,
                                instrument_function=(wn, p) -> nothing,
                                wavenumber_function=(x, p) -> x,
                                background=nothing)

The absorption coefficient α(ν) = Σₛ Nₛ · Σ σ₀·(f_l − f_u·g_l/g_u)·φ(ν) [cm⁻¹] over the SpeciesModels in species (see absorption_line). The building block behind AbsorbanceSpectrum, TransmittanceSpectrum and RadianceSpectrum's LTE path. The flat single-species keywords work as for EmissionSpectrum.

With a single species whose number_density_function is left at 1.0, the result is the effective cross-section spectrum [cm²] per molecule.

α is linear in the lineshape, so unlike the nonlinear models:

  • instrument_function is allowed: per-line convolution is exact here;
  • any per-species method works, including LDM;
  • BinAverage returns the exact bin average.

background models continuum absorption, added to α on the raw xs axis.

SpectraUtils.AbsorbanceSpectrum — Type
AbsorbanceSpectrum(; species, path_length_function,
                     instrument_function=(wn, p) -> nothing,
                     wavenumber_function=(x, p) -> x,
                     background=nothing)

Napierian absorbance A(ν) = Σₖ αₖ(ν)·Lₖ = −ln(I/I₀), i.e. the optical depth of the line of sight; decadic absorbance is A / ln(10). α(ν) sums over each slab's SpeciesModels; pass species + path_length_function (one slab) or a slabs Tuple of Slab (absorbances add). The flat single-species keywords work as for EmissionSpectrum.

Linear in α, so instrument_function and any per-species method are allowed, as in AbsorptionCoefficientSpectrum. A spectrometer measures transmittance, though: instrument-convolved absorbance matches an instrument-convolved measurement only where the slab is optically thin or the lines are resolved. Otherwise fit TransmittanceSpectrum + convolve_spectrum.

background is an additive baseline on the raw xs axis.

source
SpectraUtils.TransmittanceSpectrum — Type
TransmittanceSpectrum(; species, path_length_function,
                        wavenumber_function=(x, p) -> x,
                        background=nothing)

Transmittance T(ν) = e^{−Σₖ αₖ(ν)·Lₖ}, the normalized I/I₀ of a non-emitting line of sight. α(ν) sums over each slab's SpeciesModels, so overlapping absorbers and consecutive slabs multiply their transmittances exactly. Pass species + path_length_function (one slab) or a slabs Tuple of Slab. The flat single-species keywords work as for EmissionSpectrum.

Nonlinear in α, hence the same two caveats as RadianceSpectrum: instrument_function must return nothing (use convolve_spectrum), and BinAverage combines bin-averaged α rather than bin-averaging T (see RadianceSpectrum).

background is an additive instrumental offset (e.g. straylight) on the raw xs axis.

Synthesis method: binning and wing cutoff

SpeciesModel's method field controls how the spectrum is evaluated on the wavenumber grid: PointSample, BinAverage, LDM or SparseLDM, all from SpectralLines.jl.

With BinAverage(bin_width=...) each grid point takes the profile's average over a bin of that width centred on the point, (1/bin_width) ∫ φ(x) dx. Set bin_width to the grid spacing. The bins then tile the axis and every line keeps its area. Point sampling at a spacing comparable to the linewidth misses most of a narrow line or overweights it, depending on where its centre falls between grid points. BinAverage returns the same quantity in the same units as PointSample, and the two converge as bin_width falls below the linewidth. Use BinAverage for bin_width ≥ 0.3 × FWHM and PointSample (the default) otherwise.

wing_cut, a field on both PointSample and BinAverage, evaluates each line only within ±wing_cut × hwhm of its centre, found by binary search on the grid. The cost per line falls from the whole grid to that window, so the speedup grows with the grid span over the linewidth. Beyond the cut the line is dropped: a Lorentzian keeps about 2/(π · wing_cut) of its area outside ±wing_cut × hwhm, 0.13% at wing_cut = 500.

Backgrounds

Every model's background field takes nothing, a constant, or any callable (xs, params) -> values. It receives params, so its coefficients are fit parameters like any other.

ChebyshevBackground packages the common case, a polynomial continuum over a known interval. With FittingUtils.jl:

sp = EmissionSpectrum(; transitions, distribution_function, lineshape_function,
                        background = ChebyshevBackground(306.0, 320.0, 3))

priors = ComponentVector(Trot = Normal(500.0, 300.0),
                         background = [Normal(0.0, 1.0) for _ in 1:4])
res = fit_model(sp, xs, data, priors, LevenbergMarquardtFit())

Degree 0 is a constant offset, degree 1 a straight line.

Too low a degree biases the physical parameters, since the fit absorbs the remaining continuum into the temperature. Take the lowest degree that leaves no structure in the residuals.
