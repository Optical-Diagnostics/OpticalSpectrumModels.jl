HITRAN

OpticalSpectrumModels.HITRAN is a self-contained submodule for reading HITRAN/HITEMP line-list files (the fixed-width "HITRAN160" .par format), the bundled isotopologue metadata table, and the TIPS-2025 partition sums. It does not depend on the rest of the package; make_transition_list converts its parsed lines into ElectricDipoleTransitions.

A HITRAN line list drives the spectrum models through make_transition_list and a Boltzmann distribution with the TIPS partition sum:

lines = HITRAN.read_par("CO2.par"; wn_min = 2300.0, wn_max = 2400.0)
lines = filter(l -> l.iso == 1, lines)    # one isotopologue per species (626)
tl = make_transition_list(lines)
bd = Boltzmann(HITRAN.partition_function(2, 1), 0.0, State(:X))

A .par file holds every isotopologue of the molecule; give each its own SpeciesModel with its own partition sum. The Einstein A in the line list is abundance-free, so the number density is that of the isotopologue itself.

The pressure shift of each line is carried as pressure_shift and applied with SpeciesModel(; ..., lineshift_function = (t, p) -> t.pressure_shift * p.P), with p.P in atm.

OpticalSpectrumModels.HITRAN — Module
HITRAN

Reader for HITRAN/HITEMP line lists (fixed-width "HITRAN160" .par format).

Covers local .par files (HITRAN and HITEMP share the record format), the bundled isotopologue metadata table (molparam), the TIPS-2025 partition sums (partition_function), and the line intensity at temperature (linestrength). Not implemented: downloading, non-LTE quantum-number decoding.

OpticalSpectrumModels.HITRAN.Line — Type
Line

One parsed HITRAN/HITEMP transition record ("HITRAN160" .par format). Field names and units follow the HITRAN convention:

  • mol_id, iso: HITRAN molecule and isotopologue identifiers
  • wav: vacuum wavenumber [cm⁻¹]
  • intensity: line intensity at 296 K [cm⁻¹/(molecule·cm⁻²)]
  • A: Einstein A coefficient [s⁻¹]
  • airbrd, selbrd: air-/self-broadened HWHM at 296 K [cm⁻¹·atm⁻¹]
  • El: lower-state energy [cm⁻¹]
  • Tdpair: temperature-dependence exponent for airbrd
  • Pshft: air-pressure-induced line shift at 296 K [cm⁻¹·atm⁻¹]
  • globu, globl, locu, locl: raw global/local quantum-number strings (upper/lower); not decoded into v/J/electronic state
  • ierr, iref: uncertainty and reference index codes (raw strings)
  • lmix: line-mixing flag
  • gp, gpp: upper-/lower-state statistical weights (degeneracies)

Blank numeric fields parse to NaN: not every molecule populates every column.

OpticalSpectrumModels.HITRAN.read_par — Function
read_par(file; wn_min=-Inf, wn_max=Inf) -> Vector{Line}

Read a HITRAN or HITEMP .par file (both use the fixed-width "HITRAN160" format) into a Vector{Line}.

Only records within [wn_min, wn_max] are kept, which bounds memory and time when loading a narrow window out of a large HITEMP file.

OpticalSpectrumModels.HITRAN.is_usable — Function
is_usable(line::Line) -> Bool

Whether line carries what the spectrum models need: a positive Einstein A, positive statistical weights gp/gpp, and a non-negative lower-state energy El. Unassigned lines leave these blank, zero or negative, and make_transition_list rejects them. Drop them first:

lines = filter(HITRAN.is_usable, HITRAN.read_par("H2O.par"))

read_hitemp(files; wn_min=-Inf, wn_max=Inf) -> Vector{Line}
read_hitemp(directory; wn_min=-Inf, wn_max=Inf) -> Vector{Line}

Read and concatenate HITEMP .par files for one molecule (an explicit list, or every .par in directory), such as the wavenumber-banded chunks HITEMP ships large molecules (CO2, H2O) in. Files are read in parallel across threads.

Only records within [wn_min, wn_max] are kept, as in read_par.

OpticalSpectrumModels.HITRAN.partition_function — Function
partition_function(mol_id, iso) -> PartitionFunction

The TIPS-2025 partition sum Q(T) of a HITRAN isotopologue, callable as Q(T). Use it as the partition function of a Boltzmann distribution over HITRAN transitions:

Q = HITRAN.partition_function(2, 1)              # CO2, 626
bd = Boltzmann(Q, 0.0, State(:X))                 # energies count from the ground state

Q(T) includes the nuclear spin degeneracy, as do the HITRAN g', g'' values, so populations from the two are consistent.

OpticalSpectrumModels.HITRAN.PartitionFunction — Type
PartitionFunction

Total internal partition sum Q(T) of one isotopologue from the TIPS-2025 tables, tabulated at T = 1, 10, 20, …, Tmax K. Callable as Q(T); values agree with HAPI's partitionSum. Temperatures outside 1 ≤ T ≤ Tmax raise an error. Get one with partition_function.

Reference: Gamache et al., "Partition sums for molecules and their isotopologues for HITRAN2024", JQSRT 345, 109568 (2025). doi:10.1016/j.jqsrt.2025.109568

Fields: mol_id, iso, Tmax, Q (values on the grid).

source
OpticalSpectrumModels.HITRAN.TIPS — Constant
TIPS

Partition sums of the HITRAN isotopologues, keyed by (mol_id, iso), from TIPS-2025 as distributed with HAPI 1.3 (MIT licence, HITRAN team). Isotopologues without TIPS data, such as atomic oxygen, are absent. The Q(296 K) column of MOLPARAM comes from an earlier edition and differs by up to a factor of two for a few minor species.

OpticalSpectrumModels.HITRAN.linestrength — Function
linestrength(S_ref, El, wav, Q, T; Tref = 296.0)
linestrength(line::Line, T; Tref = 296.0)

HITRAN line intensity at temperature T from its value S_ref at Tref:

S(T) = S_ref · Q(Tref)/Q(T) · exp(-c₂ El / T) / exp(-c₂ El / Tref)
             · (1 - exp(-c₂ ν / T)) / (1 - exp(-c₂ ν / Tref))

with El the lower-state energy and wav the wavenumber in cm⁻¹, Q the partition sum callable as Q(T), and c₂ = hc/k. The Line method takes intensity, El, wav from the line and Q from partition_function. Like HITRAN's S, the result includes the natural isotopic abundance.
